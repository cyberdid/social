## Відтворюваний алгоритм

```bash
python -m unittest tests.test_contextual_candidates
python -m src.analysis.contextual_candidates
```

Сканер працює на CPU, без мережі й моделей. Він читає вже об’єднаний корпус з оригінального та розширеного збору; сирі дані не змінює. Вхід читається один раз, його хеш і розмір записуються в підсумок. Повторний запуск після оновлення вхідного файла є іншим зрізом і може дати інші числа.

## Як застосувати до коментарів і географічної підміни

Сканер приймає інші JSONL через `--input`, поля `platform`, `id`/`comment_id`, `text`, `date`, `url`. Контекст ролика можна передати полями `context_place`, `context_event_date`, `reference_event_date` або JSON-мапою URL у `--known-cases`. Це дозволяє зв’язати короткий коментар з підписом відео **без** вигадування назви місця в самому коментарі.

```bash
python -m src.analysis.contextual_candidates \
  --input comments.jsonl --known-cases known_cases.json \
  --output-prefix data/processed/comment_candidates
```

Наприклад, фраза про сліди катівні з `context_place="Софіївська Борщагівка"` отримує пояснюваний прапорець конфлікту контекстів. Але прапорець означає лише **перевірити можливу алюзію**: коментар, який не називає Петропавлівську, не можна автоматично визнати прямим твердженням про неї. Окремо фіксуються запитальна/умовна форма, цитування, заперечення та сарказм у ручному реєстрі. Зображення, звук, підтвердження місця/часу зйомки й ланцюг копій цей текстовий сканер не аналізує.

Батьківський дослідник повідомив про знайдені коментарі до конкретного TikTok; у цей запуск **їхні дані не включалися**. Тому жодне число Telegram-сканування не описує їхню кількість, аудиторію чи найранішу появу. Виявлені дописи 02.11 показують існування схожої рамки раніше, але без ланцюга поширення це **не атрибуція походження** коментарів TikTok 05.11.

## Межі й перевірка

Сканер не використовує ймовірності/рейтинги ризику. Він не визначає неправдивість за емоційністю, мовою чи належністю каналу. Повтор тексту не доводить координації; тематичний маркер не гарантує тотожності події. Регулярні правила неповні: синоніми, відео без підписів, видалені дописи й обрізані тексти залишають пропуски.

Перевірено **11 функціональних тестів**: межі слів («заметны следы»/«Слідство» не є приховуванням), швидкісний трамвай не є швидкою допомогою, «старомодне» не означає старе відео, географічне виправлення відрізняється від самого підпису Софіївської, умовна пожежа, явні дати подій, точні фрагменти, детермінованість ID і повторів. Це технічні перевірки правил, не оцінка точності фактчекінгу. Код і два первинні дописи не дають підстав називати всю хвилю доведено скоординованою дезінформацією.
