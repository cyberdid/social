# Які результати використовувати

Актуальне джерело агрегатів — `evidence_audit.json`, відбір 617 відео — `metadata_selection.csv`, скрипт — `src/analysis/youtube_evidence_audit.py`. Це ретроспективний лексичний відбір за метаданими, не повна змістова валідація.

Початковий `signals.json` і `flagged_accounts.csv` створено узагальненим Telegram-детектором. Для YouTube непридатні S3, S4, S6 та складені мітки з часовими сигналами: час коментарів приблизний, поля профілю не зібрані. Їх не можна використовувати для бот-атрибуції або частки ботів. Новий аудит обчислює лише придатні концентраційні й текстові показники окремо для всіх 30 відео та 26 відео лексичного відбору.

Повторний запуск старого `tg_comment_signals.py` на YouTube знову створить непридатні часові/профільні поля: для інтерпретації YouTube користуватися окремим аудитом.
