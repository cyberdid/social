# Instagram: стан доступу 6 листопада 2026 року

Відтворено 199 shortcode зі збереженого браузерного пошуку; 119 оцінених ID-часів лежать у зафіксованому Telegram-вікні. `candidate-times.csv` містить посилання, технічний час і прапор вікна. Відтворення: `src/analysis/instagram_candidate_times.py`. Timestamp платформи не отримано; технічне декодування використано лише для приблизного відбору, воно не встановлює час зйомки.

Спроба нового браузерного збору не дійшла до читання Instagram: підключення бачить Chrome, але документовані відкриття, вибір вкладки й навігація завершуються технічною помилкою контролю. Це не діагноз стану входу користувача й не підтвердження нової відмови Instagram. Запасна спроба відкрити один публічний URL через web tool повернула throttling на стороні завантаження. Instaloader, який раніше дістав rate-limit, повторно не запускався.

Нові підписи, реакції та коментарі отримано для 0 постів. Instagram не включається у змістові й координаційні висновки. Квитанція: `access-receipt.json`.
