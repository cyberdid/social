## Статус і межі

Case-run завершився зі статусом `partial`; структурна оцінка пройшла, а `semantic_accuracy` лишилася `not_evaluated`. Перевірочних результатів не створено: наявні 555 рядків — кандидати тверджень без незалежно встановленого scope; система не перетворює BM25-ранг або формулювання джерела на доказ істинності.

Фізичні події та причинність не були автоматично встановлені. Попередні 574 event/communication mentions лишилися згадками для розв'язання; typed physical-event records у вході немає. Source-lineage stage не запускався, тож незалежність джерел між публікаціями не встановлена. Публічні заяви МВС, НГУ, Омбудсмана, hromadske та Суспільного залишаються атрибутованими заявами відповідних джерел.

Два запити ДБР не дали збереженого тіла через помилку перевірки TLS-сертифіката. Це не свідчить про відсутність публікації. Три успішно отримані сторінки були стрічками або сторінками без придатного article-text витягу й тому додані як metadata artifacts без Passage.
