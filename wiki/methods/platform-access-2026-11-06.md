## Прийоми з посібників GIJN (Bellingcat 2020; Henk van Ess), прочитано через Wayback 06.11.2026

- **Telegram — єдина з цих платформ із публічними точними метаданими** (час до секунди). Тому контент з інших платформ варто шукати в Telegram за посиланнями `t.me` або навпаки. Ми робимо навпаки: посилання на TikTok у постах і коментарях Telegram.
- **Wayback Machine добре зберігає TikTok** («Save page now») — для фіксації доказів. Це дія у зовнішньому сервісі, тож лише за рішенням користувача.
- **Окремий дослідницький акаунт TikTok** і ручний пошук у застосунку. Алгоритм персоналізує видачу, тож «навчена» стрічка приносить більше відео на тему. Це ручний крок людини, а знайдені посилання обробляє наш конвеєр.
- **Telegram Desktop → експорт** каналу для архівування (альтернатива API).

Джерела: https://web.archive.org/web/20260121231612/https://gijn.org/stories/beyond-viral-clips-and-lip-syncing-a-guide-to-investigating-on-tiktok/ ; https://web.archive.org/web/20260926202416/https://gijn.org/resource/social-search-techniques-using-tiktok-and-telegram-from-henk-van-ess/ (оригінали на gijn.org повертають 403 для автоматичних запитів).

## Ручний протокол для платформ без безкоштовного API (Instagram, TikTok-пошук, Facebook, Threads)

1. Людина шукає в застосунку з окремого акаунта за ключовими словами й хештегами (укр./рос.) і копіює посилання в `config/manual_links.txt`, по одному на рядок, з датою пошуку.
2. Конвеєр по одному посиланню збирає метадані й коментарі (TikTok — без входу; Instagram — обережно, не більше кількох постів на день), з псевдонімізацією авторів.
3. Вибірку описуємо як **цільову (ручну)**, а не репрезентативну.
