# Computer Modern Unicode fonts

Source: https://mirrors.ctan.org/fonts/cm-unicode.zip (CM Unicode 0.7.0).
License: SIL Open Font License 1.1; see OFL.txt.

These OTF files reproduce the CMU Serif Roman/Bold/Italic and CMU Typewriter faces embedded in the five author-supplied Zenodo papers. Explicit fontspec paths prevent fallback. Figure lettering uses DejaVu Sans, as in the reference papers' Matplotlib plots.
