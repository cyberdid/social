# Social — baseline дослідницького зрізу

**Baseline commit:** `fc7e58d` (`github-upload-snapshot`)  
**Зафіксовано:** 7 листопада 2026 року  
**Робочий development branch:** `codex/social-master-plan` у локальному worktree; цей baseline не є новим upstream release.

Цей документ відділяє стан репозиторію до поточного циклу від нових прототипів. Він не оголошує дані повними й не підтверджує фактичні обставини кейсу.

## Corpus snapshot

У попередній аналітичній документації описаний цільовий Telegram-корпус: 241 канал у панелі, 23 350 дописів, 1 408 релевантних дописів, 159 каналів із релевантними матеріалами, 39 598 коментарів і 12 797 авторів із доступними ID. Це характеристики зібраної панелі, а не перепис Telegram чи репрезентативна вибірка користувачів. Сума переглядів є сумою platform snapshot counters, не унікальною аудиторією.

Покриття платформ нерівномірне; Telegram та веб-дані доступні ширше за частину інших платформ. Видалені/приватні/недоступні матеріали й API обмеження не можна трактувати як відсутність події.

## Baseline inventory

- `src/` містив collectors для Telegram, YouTube, TikTok, Instagram та вебархівування.
- `src/analysis/` містив підготовку корпусу, regex-наративи, групи каналів, текстову схожість, графові/часові сигнали та permutation null models.
- `reports/` містив кейс-специфічні агрегати, YouTube аналіз і coordination outputs.
- `tests/` містив компонентні тести; baseline не засвідчував наскрізний acceptance harness для source → evidence → report.
- Локальний масив `data/` був поза Git/ігнорувався, отже його наявність у конкретній машині не гарантується клоном.

Детальний список модулів і меж відповідальності: [поточний стан архітектури](docs/architecture/current_state.md). SHA-256/розміри доступних baseline artifacts збережені у [manifest](reports/baseline_manifest.json); його записи містять лише шляхи, статус наявності, розмір і digest, не сам вміст.

## Baseline limitations that affect conclusions

1. Telegram-панель цільова й не забезпечує population estimates.
2. Narrative regex labels змішували згадку, позицію та фактичний статус; вони збережені як legacy baseline, не ground truth.
3. Автоматичне групування каналів — сигнал-кандидат, а не доказ походження чи державного контролю.
4. Текстові повтори/часові аномалії можуть бути ознаками для перевірки, не доказом ботності або координації державного актора.
5. На момент baseline не було єдиної append-only моделі evidence/provenance, версійованої реконструкції фізичних подій або звітного gate для кожного твердження.

## Replay status

Поточний цикл відтворив задокументовані агрегати й окремі JSON/CSV-виходи на зафіксованому snapshot `continuation_20261105`. Два збережені графіки часових рядів також були перегенеровані й збіглися на рівні декодованих пікселів; байтові PNG-хеші відрізнялися. В одному CSV рядки були однакові, але tie-row порядок був недетермінований. Перелік артефактів, хеші, метод порівняння та виключення наведені у [звіті про обмежене відтворення](reports/operations/legacy-aggregate-reproduction-2026-11-08.md).

Це не засвідчує відтворення кожного legacy output: порівняння охоплює лише перелічені артефакти. Для частини інших результатів потрібні локальні ігноровані дані, окремі API доступи або інструменти, яких немає в репозиторії. Не можна заявляти про повну відтворюваність старих результатів лише на підставі наявності коду та output-файлів.

## Нові дані та immutability

Вихідні файли Telegram/вебкорпусу і користувацькі медіа не копіювалися в Git. Відео пілот зберігається у `~/Downloads/SocialIncidentVideos/`; технічний індекс і зведення у `reports/video-pipeline/` є похідними. Секрети і приватні сесії не записуються у репозиторій.
