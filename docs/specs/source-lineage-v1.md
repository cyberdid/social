# Походження доказових матеріалів Social v1

`src/analysis/source_lineage.py` фіксує залежності між доказовими записами щодо конкретного твердження. Модуль не оцінює загальну надійність видавця й не визначає першоджерело.

## Підтверджені зв'язки

- Явні поля `derived_from_evidence_ids`, `forwarded_from_evidence_id`, `quoted_evidence_ids`, `syndicated_from_evidence_id` або `translation_of_evidence_id` створюють напрямлені ребра лише тоді, коли зазначений evidence існує й належить тому самому claim.
- Однаковий валідний SHA-256 медіа створює ненапрямлене відношення `shared_media_segment`. Воно підтверджує однакові байти, але не те, хто в кого скопіював, і не місце чи час запису.

## Кандидатні зв'язки

- Точний нормалізований збіг тексту в межах того самого claim створює `possible_dependency` з `certainty=candidate`, але не напрямлене ребро.
- Кандидатна схожість тексту не входить до підтверджених компонентів залежності.
- Посилання між різними claims записуються як `invalid_references`; copy щодо іншого твердження не доводить залежності саме для поточного claim.

## Джерельні корені

- Найраніша спостережена публікація не вважається оригінальним джерелом.
- Кількість компонентів описує лише підтверджені сім'ї залежності; це не кількість незалежних спостережень.
- `independent_roots_lower_bound` лишається 0, доки незалежність не підтверджено окремими даними. Відсутність знайденого ребра не означає незалежність.

## Вхідний запис

```json
{
  "evidence_id": "evidence_001",
  "claim_id": "claim_001",
  "source_id": "source_001",
  "text": "Exact cited passage",
  "observed_at_utc": "2026-11-02T12:00:00Z",
  "media_sha256": null,
  "forwarded_from_evidence_id": null
}
```

Функція повертає детерміновані ребра, зведення сімей для кожного claim, кількість записів із невідомим lineage та нерозв'язані або міжclaim-посилання. Сто републікацій того самого файлу не збільшать число сімей залежності.
