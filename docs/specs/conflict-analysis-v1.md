# Автоматизований аналіз соціального конфлікту Social v1

## Призначення

`src/analysis/conflict_analysis.py` формує структурований `ConflictEpisode` із попередньо вилучених та прив'язаних до джерел записів. Модуль не аналізує сирий текст і не встановлює мотиви, причинність, правдивість чи позицію цілої групи. Він зберігає статуси та межі доказів, надані попередніми етапами.

## Вхідні записи

### Фізичні події

Кожен запис має `episode_id`, унікальний `event_id`, `event_kind=physical`, `action_category`, `status` і `evidence_ids`. Необов'язкові поля: `time_utc`, `actor_entity_ids`, `place_id`, `provenance_family_id`, `limitations`. Записи без доказових посилань переходять до `unresolved` і не потрапляють до серії фізичних дій. Записи `communication` у список фізичних подій заборонено передавати.

Допустимі категорії: `assembly`, `blocking`, `physical_contact`, `detention`, `medical_aid`, `negotiation`, `dispersal`, `other`, `unclassified`. Невідоме значення не відкидається: воно мапиться в `unclassified`.

### Позиції та заяви

Для `trigger`, `public_demand`, `stated_grievance`, `institutional_context`, `structural_hypothesis`, `information_interpretation`, `participant_role`, `institutional_response` та `alternative_explanation` потрібні `statement_id`, `episode_id`, текст і `evidence_ids`. Такі записи залишаються висловлюваннями джерела з полями `speaker_entity_id`, `speaker_role`, `source_id`, `status` і `alternatives`.

`represented_group_id` сам по собі не означає, що мовець представляє групу. Якщо є `representation_evidence_ids`, вони зберігаються окремо й статус стає `evidence_recorded_not_independently_validated`; автоматичної перевірки представництва немає. Цей модуль ніколи не використовує ці посилання, щоб узагальнити вимогу одного мовця до позиції групи. За відсутності таких доказів статус — `unestablished`. Невідома роль зберігається як `unknown`.

`structural_hypothesis` завжди має `epistemic_status=hypothesis`, навіть якщо збережено як джерельну заяву.

### Інформаційна увага

Кожен часовий агрегат має UTC-інтервал, `metrics` і щонайменше один `source_refs`. Метрики — скінченні невід'ємні числа; `NaN` і нескінченності відхиляються. Лічильники переглядів позначаються як snapshot counters, а не унікальні люди. Інформаційна серія зберігається окремо від фізичних дій.

## Вихід

`analyze_conflict_episode(...)` повертає:

- source-attributed `trigger`, вимоги, претензії, інституційний контекст і реакцію;
- окремі структурні гіпотези та інформаційні інтерпретації;
- `participants_and_roles` із невідомими ролями, якщо роль не встановлена;
- `physical_event_series` та `observable_actions` зі статусом кожного запису;
- `escalation_indicators` як вектор лічильників event-record за категорією, зі статусами `reported`, `supported_within_scope`, `refuted_or_superseded`;
- окрему `information_attention_series`;
- `unresolved`, глобальні `source_refs` і limitations.

Лічильники у векторі описують записи у поданому корпусі, а не реальну частоту чи тяжкість конфлікту. `provenance_family_id` допомагає бачити відомі родини залежних свідчень; відсутність такого ID не означає незалежність. Інформаційні лічильники не можуть змінити фізичний вектор.

## Інваріанти

1. Вимога одного мовця не перетворюється на позицію групи.
2. Невідома роль не вгадується.
3. Заява про подію зберігає свій вхідний статус і не підвищується до підтвердженої.
4. Відсутній evidence ref переводить запис у `unresolved`.
5. Причинність та приховані мотиви не виводяться.
6. Великий обсяг дописів чи переглядів не змінює фізичні показники.
7. Якщо вимога до evidence для інформаційного агрегату не виконана, функція завершується помилкою, а не створює непоходжений сигнал.

## Перевірка

```bash
uv run --with pytest -- python -m pytest -q tests/test_conflict_analysis.py
python -m py_compile src/analysis/conflict_analysis.py
```

Набір містить контрприклади щодо +1000 дописів без зміни фізичних записів, одиничної вимоги без підтвердження представництва, невідомої ролі та записів без джерельних посилань.

## Обмеження

Це агрегатор структурованих записів, а не засіб автоматичного визначення ескалації соціального конфлікту. Він не вирішує, чи правильно було розмічено категорію дії, роль, статус доказу, повноту покриття чи незалежність джерел. Потрібні окремі, версійовані модулі вилучення подій, верифікації доказів, lineage та аналізу чутливості.
