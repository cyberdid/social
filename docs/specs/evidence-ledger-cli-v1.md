# Evidence Ledger CLI v1

Команди виконують лише локальні файлові операції. Мережевих запитів немає. Запускати з кореня репозиторію:

```sh
python -m src.evidence_ledger_cli ingest --manifest PATH --root PATH --database PATH
python -m src.evidence_ledger_cli export-jsonl --database PATH --output PATH
python -m src.evidence_ledger_cli migrate --database PATH
```

`ingest` читає наявний маніфест Source Watch усередині `--root` і перевіряє розмір та SHA-256 кожного локального тіла через наявний міст. Повторне імпортування ідентичних записів не створює дублікатів. За наявності придатного витягу `article_text` додається Passage; інакше може бути додано лише Source та Artifact, а `counts` містить відповідний стан, зокрема `unsupported_extraction`. Статус рядка може позначати відмову в імпорті; перевіряйте лічильники навіть за коду 0. Архівні файли не змінюються.

`export-jsonl` вимагає наявну базу та створює новий файл без перезапису з правами 0600 (де підтримуються). Канонічні UTF-8 байти можна імпортувати через `EvidenceLedger.import_jsonl`; відповідь містить їх SHA-256 і кількість записів. Експорт містить самі записи та може містити чутливі шляхи й текст: зберігайте його відповідно до місцевих правил доступу.

`migrate` створює нову базу за потреби або перевіряє наявну схему. Неверсіонована база з коректною структурою v1 отримує `PRAGMA user_version = 1` без переписування записів; повторний запуск ідемпотентний. Невідома майбутня версія та некоректна структура відхиляються без зміни схеми. Відповідь містить версію та кількість записів. Відкриття `EvidenceLedger` також виконує цю перевірку і міграцію.

Символічні посилання безпосередньо на базу або вихідний файл відхиляються. Відсутні чи некоректні входи викликають помилку. Код завершення: 0 — команду виконано (для ingest окремі рядки можуть бути відхилені), 1 — операційна помилка, 2 — неправильні аргументи. Стандартний вивід містить лише JSON із лічильниками, станами або хешем; помилка не містить довільного тексту винятку. Довідка доступна через `--help`.

Перевірка цілісності байтів не встановлює достовірності джерела або істинності його тверджень. Повне автоматичне вилучення тексту не реалізоване. Міграція не є перевіркою семантичної коректності всіх історичних записів; робіть резервні копії баз перед роботою з важливими даними.
