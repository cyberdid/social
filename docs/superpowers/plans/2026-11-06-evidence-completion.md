# Завершення доказового аналізу: план виконання

> **For agentic workers:** виконувати погоджений користувачем обсяг у цій сесії; незалежні задачі делеговано за dispatching-parallel-agents.

**Goal:** перевірити джерела, виміряти незвичність координації, доповнити змістовий аналіз і видати узгоджені PDF.
**Architecture:** незмінні сирі знімки; окремі відтворювані аналізи й квитанції; інтеграція лише головною сесією.
**Tech Stack:** Python, scipy/numpy, yt-dlp, browser UI, ReportLab, Poppler.
**Spec:** погоджений список у переписці 06.11.2026 і уточнення Codex; CLAUDE.md.

## Global Constraints
- Українська мова; лише публічні дані; без платних API.
- Сирі дані не змінювати; секрети не виводити; учасників коментарів не деанонімізувати.
- Зберігати знаменники, час/джерело полів, похибки та негативні результати.
- Немає нових комітів/публікації без прямого запиту; поточна робота вже авторизована.
- Аналіз ретроспективний; цей план не видається за попередню реєстрацію.

## Задачі
- [x] Джерела: URL/HTTP аудит, локальні архіви, [22], рішення Ладики, результати перевірок; source_refresh редагує лише довідку і власний звіт.
- [x] Координація: S7 перестановки зі збереженням маргіналів; чутливість до моделі; час копій зі збереженням каналового ритму; p=(k+1)/(B+1), ефекти та інваріанти; null_models.
- [x] YouTube: top50 плюс чотири цільові доповнення за датами/форматами/маркерами, субтитри без відео, паузи/зупинка при блокуванні, обсяг та змістові кандидати тільки за отриманими текстами; youtube_content.
- [x] Контекстний сканер: відтворити пропуски зворотного порядку/словоформ і втрати parentcontext; регресійні positive/negative тести; виправлення та повторний прогін TikTok.
- [x] TikTok: таблиця часу публікації/події/зйомки/збору; невідомі поля явно порожні, ID-час окремо від платформного підтвердження.
- [ ] Instagram: поточний доступ браузера, повільний збір доступних підписів/метрик; документувати обмеження без обходу CAPTCHA/rate-limit.
- [x] Telegram: граф переходів/мостові вузли, частки наративів у 6 годинах з контрольованими знаменниками; оцінка придатності Грейнджера.
- [x] Щоденний контроль офіційних джерел: 12 фіксованих URL, незмінні знімки, початковий baseline і запуск о 10:00 Europe/Kyiv з ручною перевіркою змін.
- [x] Репозиторій: buildскрипти з tmp у scripts/reports, тимчасові рендери і псевдонімні peraccount таблиці поза git; фінальні PDF як deliverables без коміту.
- [x] Інтеграція: перевірити звіти агентів, узгодити оцінки, оновити основний Markdown/довідку/протокол, перезібрати PDF, візуально перевірити всі сторінки й журнал.

## Фактичний стан виконання

Виконано джерела, нульові моделі, 54 спроби субтитрів, контекстний пошук і часову таблицю, граф та описову динаміку, репозиторну гігієну й інтеграцію трьох PDF. Instagram: виконано перевірку доступу та офлайн-таблицю кандидатів, але новий збір підписів/метрик заблокований технічною помилкою браузерного керування до читання сторінки. Granger оцінено непридатним для цих рядів; p не обчислювалося.

Зріз джерел у головному звіті — 15:40; технічний baseline сторінок зібраний о 16:23 за Києвом. Користувацький cron установлено на 10:00 Europe/Kyiv зі збереженням попереднього завдання. Повне кодування всіх субтитрів і незалежна людська валідація лишаються подальшими етапами; не підміняються кандидатними збігами.
