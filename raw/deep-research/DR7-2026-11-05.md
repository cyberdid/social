# Доступ дослідників до даних соцмереж

Незалежні дослідники можуть легально отримувати дані з популярних платформ через офіційні інтерфейси (API) та інструменти публічної аналітики. Наприклад, TikTok пропонує **Research Tools**, до яких мають доступ схвалені академічні та некомерційні дослідники (Research API і віртуальне середовище обчислень – VCE). За умовами TikTok, дослідники повинні подати заявку, її схвалять та підписати умови («Research Tools Terms of Service»). Research API дає доступ до публічного контенту (відео, коментарі, інформація про акаунти) з лімітом ~1000 запитів на добу. VCE дозволяє запускати складні запити на соціограму відео через захищене середовище (без експорт індивідуальних даних).  

TikTok також забезпечує **Commercial Content API (Commercial Content Library)** – регуляторний інструмент для пошуку реклами в ЄС. Згідно з офіційною документацією, схвалення заявки на Commercial Content API займає близько 2 робочих днів, а подавати заявку може дослідник з будь-якої країни (зверніть увагу, що сама база охоплює лише країни Євросоюзу і деякі ЄЗВ: 27 країн ЄС, Норвегію, Ісландію, Ліхтенштейн, Великобританію, Швейцарію). Доступ безкоштовний, але обмежений 10 рекламними записами за запит (мета регуляції DSA).  

Meta (Facebook/Instagram) надає **Content Library & API** – новий інструмент для об’єднання публічного контенту з Facebook та Instagram. З листопада 2023 року Meta відкрила дослідникам можливість доступу через партнерські організації (наприклад, ICPSR в США) до графічного інтерфейсу і API Content Library, що надає дані майже в реальному часі (пости, коментарі, статистику). Отримати доступ можуть лише дослідники зі “заявників з кваліфікованих установ” за попередньою реєстрацією через партнерів (приватна безпека даних). CrowdTangle, який раніше виконував подібну роль, був скасований, тому Content Library є його фактичним наступником. Meta також має **Ad Library API** (Архів реклами) – публічний API для пошуку рекламних оголошень на Facebook/Instagram. Для використання Ad Library API потрібно зареєструвати власний додаток у Facebook Developers (безплатно), при цьому є ліміти запитів. Цей API доступний незалежно від країни та дозволяє отримувати рекламні дані (включно з політичною рекламою) для досліджень. 

Для **Threads** (додаток Meta) з червня 2024 року існує офіційний **Threads API** через Meta Graph API. Він безплатний і відкритий для розробників – в ньому можна публікувати власні треди, отримувати свої пости й метрики (ліки, перегляди, відповіді тощо). Щоб ним скористатися, потрібно створити Meta App, додати своє облікове Instagram/Meta до дозволених «тестерів» та отримати токен доступу. Вихідні тексти та інструкції доступні на сайті Meta Developers. На початковому етапі Threads API тестували лише обрані компанії (Grabyo, Hootsuite, Sprout Social тощо), але Meta обіцяє загальну доступність інтерфейсу (зараз він орієнтований на офіційні інтеграції).  

Нарешті, **YouTube** надає **Data API** (веб-інтерфейс Google APIs) – глобальний доступ до даних про відео, канали, коментарі тощо. Будь-який дослідник з Google-акаунтом може зареєструвати проєкт на Google Cloud, увімкнути YouTube Data API v3 і отримати ключ доступу. Перші кроки не вимагають затвердження, але запити обмежено квотами (їх можна збільшити за заявкою). YouTube Data API дозволяє аналізувати публічний контент без плати (є безплатні квоти). Крім того, Google запустив спеціальну **програму для дослідників** (YouTube Researcher Program), яка надає «масштабований доступ до корпусу публічних даних YouTube» з будь-яким необхідним обсягом квоти. Учасники цієї програми (за відбором) можуть отримати значно ширший доступ та технічну підтримку від YouTube.

## Доступ дослідників за Статтею 40 DSA (ЄС)

За **Європейським законом про цифрові послуги (DSA)** великі онлайн-платформи зобов’язані надавати доступ до даних затвердженим «верифікованим» дослідникам (ст. 40).  Згідно з офіційною інформацією TikTok, дослідник з сертифікованим статусом звертається через відповідний державний орган (Digital Services Coordinator); TikTok сам не приймає прямих заявок від дослідників. Після схвалення доступ надається через безпечне середовище (VCE чи сховище Dropbox). Водночас Єврокомісія повідомляла про проблеми виконання статті 40: у 2025 р. Meta і TikTok підверглися перевірці за мляве надання даних дослідникам. У попередніх висновках Комісії зазначалося, що обидві компанії створили «складні та обмежувальні процедури», які ускладнюють доступ дослідників до публічних даних. 

На практиці (2025–2026) процедура виглядає так: дослідник зі статусом «верифікованого» звертається до національного органу (в Україні це не регулюється, лише для дослідників з ЄС). Далі платформи повинні надати дані відповідно до запиту. Однак допоки не всі деталі реалізації затверджені — Директиви та підзаконні акти щодо статті 40 вступають у дію у жовтні 2025. У будь-якому разі, якщо дослідник в Україні не має «європейського верифікованого» статусу, доступ по статті 40 йому не надається безпосередньо (хіба через спільні проєкти з інституціями з ЄС).  

## Інструменти для архівування відео і стрімів

Фактчекери й OSINT-дослідники використовують спеціальні програми для збереження потокового і короткого відео. Наприклад, **Bellingcat Auto Archiver** – безплатний відкритий інструмент, який автоматично проходить за списком URL і зберігає пости з соцмереж, відео та метадані (записи, хеші, скріншоти тощо). Дослідник може внести в Auto Archiver посилання на TikTok, Telegram, Facebook тощо, і воно збереже відео та дані про нього – відмінно підходить для великого обсягу доказів. Для архівування саме відео (як-от короткі ролики чи записи стрімів) широко застосовується **yt-dlp** (форк популярного youtube-dl): цей інструмент завантажує відеоконтент з YouTube, TikTok, Instagram та інших сервісів. Для невеликих обсягів він ефективніший, ніж універсальні архіви. Крім того, часто використовують веб-архіви (Internet Archive, Archive.today) або скрипти на кшталт **Streamlink/Streamdetector** для збереження прямих ефірів. Важливо: всі ці методи повинні відповідати правилам платформ – зазвичай завантаження доступного публічного контенту не порушує ToS (поки не ухилятися від DRM чи приватних обмежень).  

## Етичні та правові рамки

Аналіз публічних постів підпадає під регулювання GDPR (для громадян ЄС) та українського Закону про захист ПДн (для України). В обох випадках пост, опублікований у відкритому доступі, не вимагає окремої згоди автора на обробку, але дані користувачів вважаються персональними, якщо можуть їх ідентифікувати. Згідно з GDPR, дослідник повинен мати правову підставу (наприклад, наукові дослідження як суспільний інтерес) та застосовувати мінімізацію даних (анонімізувати ідентифікаційні деталі, якщо можливо). Норми наукових досліджень (ст. 89 GDPR) дозволяють обробку для статистики й науки з послабленими вимогами безпеки. В Україні закон про ПДн аналогічно вимагає законної підстави (зазвичай згода чи суспільний інтерес) і передбачає обмеження на передачу особистої інформації. Загалом, дослідження публічних постів вважається етично прийнятним при дотриманні конфіденційності (не розголошувати персональні дані без потреби) і прозорості мети. Наприклад, варто видаляти з даних персональні імена, змінювати ID користувачів і не публікувати здебільшого «сирі» коментарі без обробки. Такі підходи відповідають рекомендаціям міжнародних організацій із захисту даних.
